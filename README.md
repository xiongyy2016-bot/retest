# 公众号归档助手（macOS）

这是一个用于个人或学术研究备份**正常可访问**的微信公众号文章的桌面工具。每篇文章生成一个可在 Safari 中打开的二进制 `.webarchive` 文件，图片尽量嵌入文件内部；同时输出 `文章索引.csv`（题目、作者、日期、来源链接、文件名、图片保存数量和失败原因）。可从文章链接列表、TXT/CSV 或浏览器中可见的历史页收集链接。

## 最重要的限制

- **仅输入公众号名称 ≠ 完整获取全部历史文章。** 软件以公众号名称打开公开搜索页；须用户自行进入搜索结果或历史文章页并翻页/下滑，点击「自动下滑采集」或「采集链接」。只能采集页面和已加载的公开响应中实际出现的链接，不能证明已覆盖账号全部历史文章。直接粘贴全部文章链接列表最稳妥。
- 公众号主页链接可能只能在微信内显示，外部浏览器可能要求登录/验证或无法展示历史文章；工具不会绕过登录、验证码、付费或访问限制。登录、翻页和验证都须由用户在浏览器内正常操作。
- 这是**研究友好的离线重建快照**，不是 Safari「文件 > 存储为网页归档」逐字节生成的原网页拷贝。会保留文章正文及常规图片，并移除动态脚本、互动部件；复杂 SVG、音视频、评论、投票及小程序内容不保证保留。保存失败的图片会明确标识并写入索引。存档后建议用 Safari 断网打开抽样核对。
- 请合理控制采集频率，遵守平台规则、文章版权和研究伦理。请勿公开再分发未获授权的整篇文章。

## 直接在 Mac 上运行源码

需要安装 Python 3.11+（带 Tk 界面），以及可联网下载浏览器的环境。

```bash
cd WeChatArchiver
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium
python app.py
```

首次运行会出现独立 Chromium 窗口。若用公众号名搜索，可先打开搜索结果、进入历史文章页面，翻页/滚动，再返回工具点「自动下滑采集」或「采集链接」。你也可以在文本框粘贴已有的文章链接，每行一个。选择保存位置、设置间隔，然后点「开始批量归档」。再次运行会按索引跳过已成功保存的文章，失败记录可重试。

## 构建可双击的 Mac 应用（Intel 与 Apple Silicon）

本项目内附 `.github/workflows/build-macos.yml`。把整个项目上传到你自己的 GitHub 仓库，然后在 **Actions > Build macOS apps > Run workflow** 手动运行（或推送相关文件自动运行）。两项作业分别在 `macos-15-intel` 和 `macos-15` 运行，构建包内附 Chromium 的 `.app` 压缩包。下载并解压相应架构产物，双击运行即可；无需另行安装 Python 或浏览器。生成的应用未经过 Apple 开发者签名/公证，macOS 首次打开时可能提示安全检查，可在「系统设置 > 隐私与安全性」中确认已下载应用。**该 GitHub Actions 构建流程提供了，但本工作环境不是 macOS，无法在这里实际编译或实机验证 .app。**

## 存储结构

```text
所选目录/
  公众号名称/
    文章索引.csv
    2026-09-18_示例标题_a1b2c3d4e5.webarchive
    日期未知_另一个标题_f1e2d3c4b5.webarchive
```

每篇文章的标题、来源 URL、作者、日期存于文件正文及索引；索引以 UTF-8 BOM 编码，Excel 可以正常显示中文。中途停止已完成文件不丢失。

## 测试

```bash
python -m pip install pytest
python -m pytest -q tests
```

测试覆盖 URL 识别、文章元信息、二进制归档结构与内嵌图片。没有真实公众号的端到端测试；实际可用性受页面改版、访问限制和机器网络条件影响。
